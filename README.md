# Character Map

A modern Windows character map application built with WinUI 3 and .NET 8.

## Features

- Browse Unicode characters with any installed system font
- Click characters to accumulate them in a copy field
- Copy selected characters to clipboard
- Advanced view with character set filtering, grouping, search, and Unicode navigation
- Mica Alt backdrop for native Windows look and feel
- Polish and English localization

## Building

Requires .NET 8 SDK and Windows App SDK 1.5+.

```bash
dotnet build src/charmap.sln
```

## Testing

```bash
dotnet test src/charmap.sln
```
